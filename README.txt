# Narendra Verma Portfolio

## How to run
1. Open the folder.
2. Double-click `index.html`.
3. The portfolio will open in your browser.

## Files
- index.html
- style.css
- script.js

## Before publishing
Replace:
- `your-email@example.com` with your real email.
- LinkedIn placeholder with your LinkedIn profile.
- GitHub placeholder with your GitHub profile.
- Coming-soon project cards with your real projects.
